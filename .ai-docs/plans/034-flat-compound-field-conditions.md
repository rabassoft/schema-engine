## 1. Objective

Deliver flat non-empty `all`/`any` composition of existing M30 equality
conditions while preserving every valid single predicate, controlled-state
invariant and target-neutral snapshot. The result must include descriptor-safe
compiler/manual definitions, complete ordered runtime evaluation, independent
Angular/Standard evidence and exact package/source migration proof.

Preserve completed M1–M31/G0 behavior and every unrelated checkout change. Do
not activate recursive expressions, collection/M31 conditions, M33, M34,
React or release work.

## 2. Delivery rules

1. Execute checkpoints 1–6 strictly in order and keep each intermediate source
   checkout buildable and unreleased.
2. Before each checkpoint update only `STATUS.md#In progress` with its exact
   boundary.
3. Implement/test each owned SPEC-018 row in its first owning checkpoint;
   final closure repeats but does not become first evidence.
4. Review the complete checkpoint, correct every finding and repeat the full
   review until one pass has zero findings.
5. At each completed checkpoint compact `STATUS.md` and prepend one dated
   `WORKLOG.md` entry without rewriting history.
6. Preserve package names, entry points, export maps, dependencies, manifests,
   lockfile, versions, published artifacts and current release routing.
7. Preserve independent target implementations; share authored scenarios and
   evidence contracts only.
8. Do not commit, push, release, publish or mutate external state without a
   separate explicit request from Ricard.

- implementation would contradict ADR-035 or SPEC-018;
- a Public symbol/member/reason/behavior outside SPEC-018 is needed;
- a group needs nesting, another operator, another source/target kind or
  dependency graph/cache;

  behavior to pass;
- a dependency, manifest/lockfile/package/version/release change appears;
- Angular/Standard needs shared renderer logic or definition evaluation;
- a destructive/external/Git action becomes necessary; or
- required verification repeatedly cannot pass after safe diagnosis.
