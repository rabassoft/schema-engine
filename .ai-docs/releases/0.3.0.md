## Public migration from `0.2.0`

### Core additions

The root package adds these Public Experimental contracts:

- raw UI Schema: `UiTabsSchema`, `UiAccordionSchema`,
  `UiPresentationPanelSchema`, `UiGridSchema` and `UiGridItemSchema`;
- normalized presentation: `PresentationTabsDefinition`,
  `PresentationAccordionDefinition`, `PresentationPanelDefinition`,
  `PresentationGridDefinition` and `PresentationGridItemDefinition`; and
- localized labels: `AdvancedPresentationTextMember`,
  `AdvancedPresentationLabelDefinition` and
  `AdvancedPresentationTextResolutionContext`.

`UiPresentationEntry`, `PresentationEntryDefinition` and
`TextResolutionContext` widen only for those accepted root presentation forms.
Compiler diagnostics/fallback and manual-definition validation widen
accordingly. Existing sections remain source compatible.

### Base Angular additions

The base adapter adds exactly:

- `AngularPresentationContainerDefinition`;
- `AngularPresentationContainerRenderModel`;
- `AngularPresentationContainerRenderer`;
- `AngularPresentationContainerRendererType`;
- `AngularPresentationContainerTester`;
- `AngularPresentationContainerRegistration`;
- `SchemaPresentationEntryOutletComponent`;
- `SchemaPresentationPanelOutletComponent`; and
- `provideSchemaPresentationContainer()`.

`provideSchemaEngineAngular()` keeps its signature and installs the internal
resolver plus four mandatory native registrations. `SchemaFormDirective`
projects the widened forest. Provider tokens, resolver classes, host factories,
native components and claim contexts remain Internal.

### Angular Aria pilot

The first pilot package exports only
`provideSchemaEngineAngularAriaContainers()` from its root and opt-in
`./styles.css`. It registers exactly section, tabs, accordion and grid
containers at rank `10`; it does not configure the base adapter, fields or
application theme.

The only Public Experimental style properties are:

```css
--se-aria-container-surface
--se-aria-container-text
--se-aria-container-border
--se-aria-container-accent
--se-aria-container-radius
--se-aria-container-gap
```

Applications continue to own light/dark selectors and values. Internal host
classes and selectors are not customization API.

## Angular composition and styles

Every Angular application installs the base provider directly or through the
native provider used by the complete native form setup. The pilot is optional
and is registered after it:

```ts
import { provideSchemaEngineAngularNative } from '@rabassoft/schema-engine-angular';
import { provideSchemaEngineAngularAriaContainers } from '@rabassoft/schema-engine-angular-aria';

bootstrapApplication(AppComponent, {
  providers: [
    provideSchemaEngineAngularNative(),
    provideSchemaEngineAngularAriaContainers(),
  ],
});
```

Import the pilot baseline explicitly when desired:

```css
@import '@rabassoft/schema-engine-angular-aria/styles.css';
```

Without the pilot, mandatory native containers remain available. Without its
stylesheet, pilot semantics remain functional but no visual baseline is
applied.
