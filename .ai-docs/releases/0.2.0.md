- **Angular target:** `@rabassoft/schema-engine-angular@0.2.0`

## Included capability

This coordinated MINOR contains completed M14/SPEC-006 nullable primitive
leaves. The compiler accepts only exact two-member primitive-plus-null type
arrays at supported editable leaves, normalizes the required `nullable`
capability and preserves all scalar, container, identity, enum and general-union
exclusions. Existing definition-aware operations/runtime accept explicit null
only for nullable leaves. Native string, number/integer and boolean renderers
provide the accepted localized set-null intention and confirmed-null status;
string enum remains excluded.

## Source migration from 0.1.0

1. Every manually authored primitive `FieldDefinition` or `FieldTemplate` adds
   required `nullable: boolean`. Use `false` for scalar leaves and `true` only
   for the exact accepted nullable primitive-leaf capability. Definitions
   produced by `compileFormDefinition()` already contain the member.
2. Every manually authored `AngularFieldTextSnapshot` adds required
   `setNullLabel` and `nullValueLabel`. Exhaustive handling of `FieldTextMember`
   adds `set-null` and `null-value`.

No operation shape, expectation, presence/snapshot contract, runtime method,
renderer registration, output, provider, export or entry point changed. Every
affected API remains Experimental.

## Distribution boundary

Both candidates retain root-only exports, complete package-local preferred
TypeScript source and frozen build harnesses, the exact AGPL license/notices and
no private repository URL. GitHub remains private, so no npm provenance,
trusted publisher or staged workflow is claimed. Candidate preparation uses a
neutral publication path to prevent repeating `0.1.0`'s registry-generated
local username/workspace disclosure.

Live `0.1.0` bytes remain immutable and pre-M14. Until both `0.2.0` packages
are actually published and verified, `next` and mandatory Experimental
`latest` continue to route according to the observed registry state rather than
this candidate document.

## Exclusions

General unions, standalone null, nullable root/object/array/item/identity,
`enum + null`, coercion, defaults, arrays of primitives, dynamic/external
references, async validation, persistence, new renderers, Stable APIs,
repository publication and D-043 remain outside this release.
