## Included capabilities

- Framework-neutral compilation of the SPEC-001 through SPEC-004 root-object,
  recursive object, primitive-leaf, homogeneous object-collection and static
  same-document local-reference subset with explicit identity policies.
- Immutable strict deep operations and controlled runtime state with object and
  leaf snapshots, scopes, presence, dirty and validation projection.
- Synchronous external validation, interaction state, scopes, localization and
  immutable snapshots/subscriptions.
- Stable collection/item/node reads and controlled item-leaf set/remove plus
  application-supplied insert, remove and move intentions.
- Angular 22 headless adapter with automatic recursive object/leaf projection,
  fixed stable-keyed collection/item projection, localized semantic groups,
  canonical IDs, scored leaf-renderer resolution and inline `ViewContainerRef`
  instantiation.
- Accessible native string, number/integer, boolean and string-enum renderers
  using private Angular Signal Forms buffers.
- Controlled explicit field clearing that distinguishes missing from `""`,
  `0`, negative zero and `false`.
- Static neutral presentation sections with normalized immutable definitions,
  deterministic fallback and fixed accessible Angular projection.

These outcomes correspond to completed M1–M12 and G0 under SPEC-001 v0.1.15,
SPEC-002 v0.1.2, SPEC-003 v0.1.2 and SPEC-004 v0.1.1. PLAN-011 completed all
five checkpoints, while SPEC-005 v0.1.1 and PLAN-012 revision 1 govern the
static-presentation slice. Their repeated final reviews passed with zero
findings.

## Stability and migration policy

All root exports remain Experimental. During `0.y`, an incompatible
Experimental API change requires at least a MINOR release, an approved SPEC,
ADR, or plan, and migration notes when repository consumers exist. Neither
`0.1.0` nor packaging promotes an API to Stable.

Only explicit package root entry points are supported. Deep imports are not
part of the public API.

The M9 Experimental migration changes canonical definition/runtime keys from
root field names to serialized deep paths, extends operations and lookup APIs
to string-only deep paths, and replaces repository consumers' manual flat-field
projection with automatic `SchemaFormDirective` object/leaf projection. These
source-level changes remain governed by the `0.y` Experimental policy.

The M10 Experimental migration adds array definitions, item templates, stable
collection addresses, five collection operation variants, positional read
paths and fixed Angular collection/item projection. Numeric paths remain
observation-only; applications continue to own values, identity and controlled
confirmation.

The M11 Experimental behavior accepts the closed SPEC-004 root `$defs` and
supported non-root fragment-only `$ref` subset. Resolution remains Internal;
Public definitions/signatures, runtime ownership and Angular APIs are
unchanged.

## Known exclusions

Arrays of primitives, arrays inside collection item templates, tuples, external
or dynamic references, anchors, JSON Schema composition, generated/editable
identity, async validation, persistence, advanced layout beyond static
sections, custom collection renderers, theming, plugins, undo/redo, publication
automation, and all other deferred capabilities remain excluded.
