# Schema Engine 0.1.0 local candidate notes

- **Candidate date:** 2026-07-14
- **Publication state:** Unpublished; local verification only
- **API state:** Public + Experimental + Active
- **Core candidate:** `@rabassoft/schema-engine@0.1.0`
- **Angular candidate:** `@rabassoft/schema-engine-angular@0.1.0`

## Included capabilities

- Framework-neutral compilation of the SPEC-001 root-object and primitive-field
  subset.
- Immutable strict root operations and controlled runtime state.
- Synchronous external validation, interaction state, scopes, localization and
  immutable snapshots/subscriptions.
- Angular 22 headless adapter with scored renderer resolution and inline
  `ViewContainerRef` instantiation.
- Accessible native string, number/integer, boolean and string-enum renderers
  using private Angular Signal Forms buffers.
- Controlled explicit field clearing that distinguishes missing from `""`,
  `0`, negative zero and `false`.

These outcomes correspond to completed M1–M7 and G0 under SPEC-001 v0.1.15.

## Stability and migration policy

All root exports remain Experimental. During `0.y`, an incompatible
Experimental API change requires at least a MINOR release, an approved SPEC,
ADR, or plan, and migration notes when repository consumers exist. Neither
`0.1.0` nor packaging promotes an API to Stable.

Only explicit package root entry points are supported. Deep imports are not
part of the public API.

## Known exclusions

Nested objects, arrays, JSON Schema composition and references, async
validation, persistence, advanced layout, theming, plugins, undo/redo,
publication automation, and all other deferred capabilities remain excluded.

## Distribution boundary

These tarballs remain `private: true`, have no selected license or distribution
terms, and are not authorized for external distribution. No registry write,
publication, Git tag, GitHub Release, provenance operation, credential use, or
API stability promotion occurred. D-040 and D-034 retain those decisions.
