# React reference application

Private independent React reference shell defined by ADR-038, SPEC-021 and
PLAN-037 checkpoint 7.

The client-only `createRoot` + `StrictMode` application consumes Public package
roots and the neutral scenario catalog. It owns value/baseline, decisions,
locale, validation visibility, async-service evidence, editable Schema/UI
Schema drafts, theme, snippets, tests and cleanup independently from the
Angular and Standard shells.

Run `pnpm reference:react:dev` from the repository root and open
`http://127.0.0.1:4213`. This project remains private evidence for an
Experimental adapter and is not publishable consumer documentation.
