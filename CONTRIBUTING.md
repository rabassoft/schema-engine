# Contributing

Schema Engine welcomes reproducible bug reports, documentation feedback, usage
questions and security reports. The packages remain Public + Experimental and
there is currently no support SLA.

## Issues and non-code feedback

Before opening an Issue, check the current README, specifications and existing
Issues. A useful report includes:

- the exact Schema Engine, framework and runtime versions;
- a minimal schema, UI Schema or reproduction;
- expected and observed behavior; and
- relevant diagnostics without credentials or private data.

Security vulnerabilities must follow [SECURITY.md](./SECURITY.md), never a
public Issue.

## Code contributions

External code contributions are not currently accepted. Schema Engine uses an
AGPL-3.0-only/commercial dual-license model, and commercial relicensing requires
a separately reviewed CLA or copyright-assignment policy that does not yet
exist.

You may discuss an implementation idea or provide a minimal reproduction, but
please do not submit production code, generated patches or pull requests for
merging. Unsolicited code submissions will be closed without merge; submitting
one does not transfer copyright or grant Rabassoft relicensing rights.

This boundary may change only through a documented future decision. Until then,
Issues and other non-code feedback remain the supported public collaboration
route.

## Conduct and licensing
